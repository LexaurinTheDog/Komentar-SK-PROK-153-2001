# Komentár k zákonu č. 153/2001 Z. z., o prokuratúre

Odborný komentár k slovenskému zákonu o prokuratúre — základnému predpisu upravujúcemu postavenie a pôsobnosť prokuratúry Slovenskej republiky, sústavu prokuratúry (Generálna prokuratúra, krajské a okresné prokuratúry, Úrad špeciálnej prokuratúry), vzťahy medzi prokurátormi, vydávanie pokynov, prokurátorský dozor nad zachovávaním zákonnosti, ako aj postavenie a povinnosti prokurátorov, asistentov prokurátora a právnych čakateľov prokuratúry. Zákon nadobudol účinnosť 1. mája 2001. Komentár pokrýva celý zákon (§ 1 – § 58) — **92 paragrafových jednotiek**; zákon neobsahuje novelizačné články meniace iné zákony.

Konsolidované znenie k **12. 6. 2026**, zdroj [slov-lex.sk](https://www.slov-lex.sk/static/SK/ZZ/2001/153/20260612.html).
